## 🚨 RECRUITMENT RED FLAGS

### Individual Disqualifiers
- "Data speaks for itself" believers
- Never been poor or food insecure
- No community-based work
- Prize/glory seekers
- Documentation haters
- Conflict avoiders
- Uses "just" to describe any task
- Calls communities "underserved" not "abandoned"
- Savior complex evident
- "Move fast break things" mindset

### Team Culture Killers
- All Ivy League backgrounds
- All urban or all rural
- All white team leadership
- No one receiving benefits
- No one from studied communities
- All English speakers
- All technical or all humanities
- No one who's failed publicly
- Excessive meeting culture
- Credit seekers not builders

## Accessibility Philosophy

### Universal Design Principles
1. **Perceivable**: Information available to all senses
2. **Operable**: All functions keyboard accessible
3. **Understandable**: Clear to diverse cognitive abilities
4. **Robust**: Works with all assistive technologies
5. **Dignified**: No separate but equal

### Technical Standards
- **WCAG**: AAA not AA (go beyond minimum)
- **ARIA**: Use semantic HTML first, ARIA to enhance
- **Testing**: Automated + manual + disabled users
- **Documentation**: How to use with AT
- **Support**: Accessibility-specific help channel

### Code Review Checklist
```javascript
// David's accessibility review
const accessibilityReview = {
  keyboard: {
    tabOrder: 'logical',
    skipLinks: 'present',
    focusIndicators: 'visible',
    trapsAvoided: true
  },
  screenReader: {
    landmarks: 'semantic',
    headingStructure: 'hierarchical',
    altText: 'descriptive',
    announcements: 'helpful'
  },
  cognitive: {
    language: 'plain',
    instructions: 'clear',
    errors: 'understandable',
    timeouts: 'generous'
  },
  motor: {
    targetSize: '44x44px minimum',
    spacing: 'adequate',
    alternatives: 'provided'
  }
}
```

### Testing Protocol
1. Keyboard only navigation
2. Screen reader testing (NVDA, JAWS, VoiceOver)
3. Voice control testing
4. Cognitive load assessment
5. Real disabled user sessions

## 🖼️ FIRST DESIGN DECISIONS

### Color Palette Philosophy
"No red/green (poverty/wealth) binaries. We're using earth tones that don't scream crisis but whisper resilience."

### Typography Choices
- **Primary**: Atkinson Hyperlegible (accessibility)

- Desktop: Progressive enhancement only

- Offline: Full functionality retained
